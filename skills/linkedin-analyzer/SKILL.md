# LinkedIn Profile Analyzer

LinkedIn 본인 프로필의 이력, 소개, 경력, 학력, 게시글, 활동 등을 분석하여 관심사, 강점, 전문성을 도출하고 최적화된 프로필 개선안을 추천합니다.

## 인자

- `$ARGUMENTS`: (선택) 출력 파일명. 미지정 시 `{이름}-linkedin-analysis.md`

## 사전 요구사항

- Chrome 브라우저에서 LinkedIn에 로그인된 상태
- claude-in-chrome MCP 설치 및 연결

## 실행 워크플로우

### Step 1: 환경 확인 및 본인 프로필 보호

Chrome MCP 도구 사용 가능 여부를 확인합니다.

1. `mcp__claude-in-chrome__tabs_context_mcp`를 호출하여 Chrome 연결 확인
2. 연결 실패 시 → **폴백 모드** (Step 1-B)로 이동

**본인 프로필 보호:**
- 이 스킬은 **본인 프로필 분석 전용**입니다
- `linkedin.com/in/me`로 이동하여 본인 프로필을 보장합니다
- 사용자가 타인 프로필 URL을 제공한 경우 차단합니다:
  > "이 스킬은 본인 프로필 분석 전용입니다. LinkedIn에 로그인한 상태에서 본인 프로필을 분석합니다."

### Step 1-B: 폴백 모드 (Chrome MCP 미설치)

Chrome MCP를 사용할 수 없는 경우:

> "Chrome MCP가 연결되지 않았습니다. 수동 모드로 전환합니다.
>
> LinkedIn 프로필 페이지에서 아래 정보를 복사하여 붙여넣어 주세요:
> 1. 프로필 페이지 전체 텍스트 (이름, 헤드라인, 소개, 경력, 학력)
> 2. (선택) 활동 페이지의 최근 게시글
>
> 또는 LinkedIn '데이터 다운로드' 기능으로 내보낸 CSV 파일 경로를 알려주세요."

수동 입력을 받은 후 Step 3으로 건너뜁니다.

### Step 2: 프로필 데이터 수집

Chrome MCP를 사용하여 본인 프로필 데이터를 수집합니다.

**2-1. 프로필 페이지 수집:**

1. `mcp__claude-in-chrome__navigate`로 `https://www.linkedin.com/in/me` 이동
2. `mcp__claude-in-chrome__get_page_text`로 프로필 전체 텍스트 추출
3. 추출된 텍스트에서 확인할 항목:
   - 이름, 헤드라인
   - 소개(About)
   - 경력 사항 (회사명, 직함, 기간, 직무 기술)
   - 학력
   - 보유 기술
   - 관심 분야 (팔로우 중인 회사, 뉴스레터, 인플루언서)

**2-2. 활동 페이지 수집:**

1. `mcp__claude-in-chrome__navigate`로 `https://www.linkedin.com/in/me/recent-activity/all/` 이동
2. `mcp__claude-in-chrome__get_page_text`로 활동 텍스트 추출
3. 수집 대상:
   - 직접 작성한 게시글
   - 퍼온(공유한) 게시글
   - 댓글 활동

### Step 3: 프로필 분석

수집된 데이터를 기반으로 다음을 분석합니다:

**3-1. 관심사 패턴 분석:**
- 게시글/공유/활동에서 반복되는 주제 키워드 식별
- 관심 분야 클러스터링 (기술, 산업, 트렌드, 커리어)
- 팔로우 중인 회사/뉴스레터에서 드러나는 관심 방향

**3-2. 강점 도출:**
- 경력 진행도 분석 (직급, 책임 범위 변화)
- 직무 기술에서 반복되는 핵심 역량
- 게시글 주제와 전문 영역 교차 분석

**3-3. 전문성 매핑:**
- 경력 + 학력 + 기술 + 활동 종합 전문성 프로파일
- 주 전문 영역 vs 부 전문 영역 구분
- 숨겨진 전문성 발견 (경력에는 없지만 활동에서 드러나는 분야)

### Step 4: 프로필 최적화 추천 생성

분석 결과를 바탕으로 구체적인 개선안을 생성합니다:

**4-1. 헤드라인 최적화:**
- 현재 헤드라인 평가
- 3개의 대안 제안 (키워드 최적화 + 차별화)
- 각 대안의 장단점

**4-2. 소개(About) 리라이팅:**
- 현재 소개 평가 (구조, 키워드, 스토리텔링)
- 개선된 소개문 제안
- 변경 이유 설명

**4-3. 경력 기술 강화:**
- 각 경력별 현재 기술 방식 평가
- 성과 중심 서술로 전환 제안 (수치, 임팩트 강조)

**4-4. 콘텐츠 전략:**
- 현재 활동 패턴 분석 (게시 빈도, 주제, 참여도)
- 추천 게시 주제 (전문성 강화에 도움되는 방향)
- 추천 게시 빈도 및 포맷

### Step 5: 리포트 출력

분석 결과를 Markdown 파일로 저장합니다.

**파일명**: `$ARGUMENTS`가 있으면 해당 파일명, 없으면 `{이름}-linkedin-analysis.md`

**리포트 구조:**

```markdown
# LinkedIn 프로필 분석 리포트 - {이름}

**분석일:** YYYY-MM-DD
**프로필:** https://www.linkedin.com/in/{username}

## 1. 프로필 요약
(현재 프로필의 핵심 정보 요약)

## 2. 강점 분석
(도출된 핵심 강점과 근거 데이터)

## 3. 관심사 맵
(관심 분야 클러스터 및 트렌드)

## 4. 전문성 프로파일
(주/부 전문 영역 매핑)

## 5. 개선 추천
### 5-1. 헤드라인
| 현재 | 추천 | 이유 |
### 5-2. 소개(About)
(현재 → 추천 변경 → 이유)
### 5-3. 경력 기술
(각 경력별 강화 포인트)
### 5-4. 콘텐츠 전략
(추천 게시 주제, 빈도, 포맷)

## 6. 액션 아이템
### 즉시 실행 (이번 주)
### 단기 (1개월)
### 장기 (3개월)
```

저장 후 파일 경로와 요약 정보를 출력합니다.

## 주의사항

- **본인 프로필만 분석 가능합니다.** 타인 프로필 URL을 입력하면 차단됩니다.
- LinkedIn 페이지 구조가 변경되면 수집 결과가 달라질 수 있습니다. 수집 실패 시 수동 모드를 안내합니다.
- 부분 데이터만 수집된 경우에도 가용 데이터로 분석을 진행합니다 (그레이스풀 디그레이데이션).
- 수집된 데이터는 분석 세션 중에만 사용되며 영구 저장하지 않습니다. 리포트 파일만 저장됩니다.
- 긴 프로필(경력 10개+)의 경우 토큰 사용량이 증가할 수 있습니다.

## 예시

```bash
# 기본 실행 (파일명 자동 생성)
/gnoyes:linkedin-analyzer

# 파일명 지정
/gnoyes:linkedin-analyzer report.md
```
