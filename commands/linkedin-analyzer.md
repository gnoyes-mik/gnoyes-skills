# LinkedIn Profile Analyzer

LinkedIn 본인 프로필을 분석하여 관심사, 강점, 전문성을 도출하고 최적화된 프로필 개선안을 추천합니다.

## 사용법

LinkedIn에 로그인된 Chrome 브라우저가 필요합니다. 선택적으로 출력 파일명을 인자로 전달합니다.

## 워크플로우

1. Chrome MCP로 LinkedIn 본인 프로필(`/in/me`) 데이터 수집
2. 활동 페이지(게시글, 공유, 댓글) 수집
3. 관심사 패턴, 강점, 전문성 분석
4. 헤드라인/소개/경력/콘텐츠 전략 개선안 생성
5. Markdown 리포트 파일로 저장
